# Advanced Selenium Grid and Cloud

Learning project based on the Udemy course:

**Advanced Selenium Grid and Cloud | SauceLabs and Jenkins**

Instructor: Dmitry Shyshkin

## About This Repository

This repository contains my learning progress while following the
"Advanced Selenium Grid and Cloud | SauceLabs and Jenkins" course.

The goal is to improve my knowledge of Selenium WebDriver automation
with Java and TestNG, with a focus on executing automated tests locally,
on Selenium Grid, in cloud-based testing platforms, and through CI/CD
with Jenkins.

## Learning Objective

The main objective of this project is to understand how a Selenium
automation framework can evolve from local browser execution into a
framework capable of running tests on Selenium Grid, cloud platforms,
and CI/CD pipelines.
